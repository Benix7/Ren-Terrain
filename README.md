# Ren Terrain

**Ren Terrain** is an atmospheric open-world exploration game built in **Unity Engine**, featuring a detailed forest environment designed with an AAA-inspired visual style.

Step into the shoes of **Ren**, the game's playable protagonist, and explore a vast, immersive forest filled with dense vegetation, natural landscapes, atmospheric lighting, and carefully crafted environments.

There is no fixed path to follow. **You decide where to go, what to explore, and what you discover along the way.**

### Key Features

- 🌲 Large, detailed open-world forest
- 🎮 Play as **Ren**, the main protagonist
- 🏞️ AAA-inspired environment and visual design
- 🌫️ Atmospheric lighting and immersive weather
- 🚶 Free exploration with no fixed route
- 🎨 Built entirely using **Unity Engine**
- 🌎 Focus on exploration, atmosphere, and immersion

**Ren Terrain** is a project focused on creating a cinematic, immersive world where the environment itself becomes part of the experience.
